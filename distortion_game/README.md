# Искажение - Настольная игра

Приложение-компаньон для настольной игры "Искажение" на Flutter.

## Структура проекта

```
lib/
├── main.dart                 # Точка входа в приложение
├── screens/                  # Экраны приложения
│   ├── main_menu_screen.dart    # Главное меню
│   ├── characters_screen.dart   # Экран персонажей
│   ├── settings_screen.dart     # Настройки
│   ├── setup_screen.dart        # Настройка партии
│   └── game_screen.dart         # Игровое поле
├── widgets/                  # Переиспользуемые виджеты
│   ├── menu_button.dart      # Кнопка меню
│   └── distortion_counter.dart # Счётчик искажения
├── models/                   # Модели данных
│   ├── character.dart        # Модель персонажа
│   ├── location.dart         # Модель локации
│   └── game_state.dart       # Состояние игры
├── data/                     # Данные (локации, события и т.д.)
│   ├── locations_data.dart   # Список всех локаций
│   └── events_data.dart      # События
└── utils/                    # Утилиты
    └── save_manager.dart     # Сохранение/загрузка прогресса
```

## Запуск

1. Убедитесь, что Flutter установлен и настроен
2. Откройте проект в VS Code
3. Запустите команду `flutter run`

## Особенности

- Модульная структура для лёгкого добавления нового контента
- Подробные комментарии в коде
- Сохранение прогресса партии
- Генерация случайной карты из локаций
